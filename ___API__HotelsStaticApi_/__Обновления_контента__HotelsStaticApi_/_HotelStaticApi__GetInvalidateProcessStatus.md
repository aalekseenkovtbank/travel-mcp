# Общая информация

| Назначение | Метод возвращает статус процесс инвалидации данных. Процесс инвалидации может быть запущен только один. |
|---|---|
| Бизнес-процессы | Отслеживание изменений в статике \[HotelStaticApi]<br />Обновление контента на стороне потребителя \[HotelStaticApi] |
| Контракт | ```<br />/internal_api/v1/static_data/invalidate_process_status<br />``` |

# Алгоритмы работы метода

## MC.Основной сценарий

1. Сделали запрос в таблицу CMS.InvalidateStaticData
2. Сгруппировали по CreateAt записи
3. Взяли последнюю по дате и времени группу
4. Проверили статусы во взятой группе 
   
   1. Если в группе у всех записей есть значение status = 0. Вернули передали в Status значение New
   2. Если в группе у одной или нескольких записей есть значение status = 3. Вернули передали в Status значение Failed
   3. Если в группе у одной или нескольких записей есть значение status = 1 и нет записи со status = 3. Вернули передали в Status значение InProgress
   4. Если в группе у всех записей есть значение status = 2. Вернули передали в Status значение Success
5. Сформировали и передали ответ
