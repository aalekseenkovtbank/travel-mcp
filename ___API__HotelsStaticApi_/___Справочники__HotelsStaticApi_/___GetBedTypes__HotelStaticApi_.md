# Протокол

## Структура запроса

GET-запрос без входных параметров

## Структура ответа

| Параметр | Тип | Обязательность | Описание |
|---|---|---|---|
| masterId | int4 | MANDATORY | Идентификатор кровати в мастер-системе.<br />TravelDB..BedType.BedTypeId |
| nameRu | string | MANDATORY | Название кровати на русском языке.<br />TravelDB..BedType.NameRu |
| nameEn | string | Optional | Название кровати на английском языке.<br />TravelDB..BedType.NameEn |

## MC.Основной сценарий

Для каждого метода должен быть обязательно определен один основной сценарий (MC). В MC описывается базовый (наиболее частый или наиболее короткий) позитивный сценарий работы метода. 

1. Разбирается полученный запрос
2. Выполняется получение всех доступных кроватей из TravelDB: возвращаются только кровати с заполненным полем NameRu в базе. С незаполненным полем кровати игнорируются
3. Основной сценарий завершается.
